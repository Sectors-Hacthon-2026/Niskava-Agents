6 Hukum Arsitektur Non-Negotiable
Law 1 • Deterministic
Deterministic Before Generative
Seluruh metrik kuantitatif (Volume MA20, Z-score, abnormal return, divergensi sektor) dihitung secara deterministik dengan NumPy/Pandas sebelum memanggil LLM. Menghapus halusinasi numerik 100%.
Law 2 • Compliance
Strict Financial Non-Advisory Boundary
Niskava adalah terminal intelijen investigatif, BUKAN penasihat investasi. Sistem tidak pernah memberikan rekomendasi BELI/JUAL atau target harga (Kepatuhan Hackathon Rule 12). Bukti diklasifikasikan ke dalam 3-Tier: SUPPORTED, UNCERTAIN, CONTRADICTED.
Law 3 • Execution
Prohibition of Automated Trade Execution
Sistem bersifat murni read-only market intelligence. Tidak ada integrasi broker atau eksekusi order trading otomatis (Kepatuhan Hackathon Rule 06).
Law 4 • Sovereignty
Local-First Data Sovereignty
Semua sesi investigasi, temuan bukti, graf memori, dan riwayat percakapan disimpan secara lokal di mesin Anda menggunakan SQLite WAL (~/.niskava/niskava.db). Tanpa cloud DB pihak ketiga.
Law 5 • Discipline
Credit Budget Discipline & Local Caching
Data candlestick harian historis (T < hari ini) di-cache permanen di SQLite lokal untuk melindungi kuota grant 1.000 kredit Sectors API v2, menjamin biaya 0 kredit untuk query berulang.
Law 6 • Graph Memory
Local Conversational Graph Memory Engine
Memori asosiatif multi-entitas dikelola lokal menggunakan NetworkX in-memory dengan penelusuran Ego-Graph (k ≤ 2 hop) dan peluruhan waktu eksponensial (recency decay).

Metrik Kuantitatif Vz ≥ 2.50σ
Volume Z-Score (Vz)
Ukuran statistik seberapa jauh volume transaksi saham hari ini menyimpang dari rata-rata volume 20 hari sebelumnya (MA20). Nilai Vz ≥ 2.50σ mengindikasikan lonjakan volume perdagangan yang tidak wajar dan memicu investigasi mendalam.
Rumus: Vz = (Volume_t - MA20_vol) / StdDev20_vol
Aksi Harga |Rt| ≥ 5.0%
Abnormal Return (Rt)
Deviasi pergerakan harga saham di luar ekspektasi normal pasar setelah memperhitungkan pergerakan indeks acuan. Nilai |Rt| ≥ 5% menandakan pergerakan harga ekstrem yang berpotensi memiliki katalis informasi terselubung.
Rumus: Rt = R_saham - (Alpha + Beta * R_market)
Baseline Likuiditas 20 Hari Bursa
Moving Average 20 (MA20 Volume)
Rata-rata volume perdagangan harian selama 20 hari bursa aktif (~1 bulan kalender). Berfungsi sebagai patokan likuiditas normal emiten untuk mengukur rasio kelipatan volume.
Aliran Dana Asing |Fz| ≥ 2.50σ
Foreign Flow Z-Score (Fz)
Skor anomali arus modal bersih investor asing (Net Foreign Buy/Sell). Menunjukkan apakah akumulasi atau distribusi investor institusional asing terjadi dalam skala yang signifikan secara statistik.
Bandarmology C3 ≥ 65%
Top Broker Concentration (C3)
Rasio penguasaan akumulasi volume beli bersih oleh 3 kode broker/sekuritas teratas dibandingkan total volume pasar. Nilai C3 ≥ 65% menandakan transaksi sangat terkonsentrasi di tangan segelintir pelaku institusional.
Komparasi Industri Peers Benchmark
Sector Divergence (Dt)
Selisih persentase antara perubahan harga saham target dengan rata-rata pergerakan emiten sejenis di subsektor industrinya. Mengidentifikasi apakah pergerakan saham didorong oleh faktor spesifik emiten atau sentimen sektoral.
